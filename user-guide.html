Getting started

Renamix is a Windows desktop application for renaming many files at once. After installing it, open the application to see the main window, which is split into a file list on one side and rename options on the other.

Every rename you build in Renamix runs through the same basic flow: select files, define how the new names should look, check the preview, then apply the rename.

Selecting files

Add files to Renamix using one of the following methods:

  1. Click Add Files and browse to the files you want to rename.
  2. Click Add Folder to load every file inside a folder.
  3. Drag and drop files or folders directly into the Renamix window.

Selected files appear in the file list with their current names. You can remove individual files from the list without affecting them on disk — removing a file from the list only removes it from the current renaming session.

Creating a rename pattern

A rename pattern is the set of rules Renamix applies to every selected file. You can combine several rule types together:

  • Prefix — add text to the beginning of each filename.
  • Suffix — add text to the end of each filename, before the extension.
  • Replace & remove text — find specific text in filenames and replace or delete it.
  • Change case — convert names to UPPERCASE, lowercase, Title Case, or Sentence case.
  • Extension control — change, add, or remove the file extension.

Rules are applied in order, so the sequence in which you add them affects the final result. Use the preview panel to check the outcome as you go.

Example pattern: add the prefix Vacation_, then apply sequential numbering, to turn IMG_0294.jpg into Vacation_001.jpg.

Using sequential numbering

Sequential numbering appends or inserts an auto-incrementing number into each filename. You can configure:

  • Start value — the number the sequence begins at (for example, 1 or 0).
  • Step — how much the number increases by for each file (usually 1).
  • Padding — how many digits the number should use, such as 001 instead of 1.
  • Position — where the number appears in the new filename.

Files are numbered in the order they appear in the file list, so sort or reorder the list first if the order matters.

Previewing names

As you build your rename pattern, the preview column updates automatically to show what each file's new name will be. Nothing on disk changes until you apply the rename — the preview is always safe to experiment with.

Look for naming conflicts before renaming. Renamix highlights filenames that would collide with another file in the same folder.

Renaming files

Once the preview looks correct, click Rename to apply the changes. Renamix processes the selected files and updates their names on disk.

Large batches may take a moment to complete depending on the number of files and their location. Avoid modifying the same files in another program while a rename is in progress.

Undoing a rename

If a rename doesn't turn out the way you expected, click Undo to reverse the most recent batch rename and restore the original filenames.

Undo reverses the last rename operation. It is good practice to check the preview carefully before renaming, especially for large batches.

Filtering files

Use the filter options to narrow the file list before renaming, so your pattern only applies to the files you actually want to change. You can filter by:

  • File extension (for example, only .jpg files)
  • Text contained in the filename
  • Simple name patterns

Filtering only changes which files are included in the current session — it doesn't move or delete anything.

Troubleshooting

Common issues and things to check:

A file didn't get renamed

Check whether the file is open in another program, or whether it's marked as read-only. Files that are locked by another application can't be renamed until they're closed.

The preview shows a naming conflict

A naming conflict means two or more files would end up with the same name. Adjust your pattern — for example, by adding sequential numbering — so each result stays unique.

Undo isn't available

Undo reverses the most recent rename operation. If you've closed Renamix or performed another rename since then, undo history may no longer be available.

Renamix won't open

Confirm you're running a supported version of Windows. If the issue continues, reach out through the contact link in the footer for support.
