User Guide

Learn how Renamix works.

A short, practical walkthrough of every step from opening the app to renaming your first batch of files.

Introduction

Renamix is a batch file renaming tool for Windows. Instead of renaming files one at a time, you build a small set of rules — a prefix, a text replacement, a case change — and apply them to as many files as you've selected, all in one pass.

Every rule shows you the result before it happens. Nothing is renamed until you confirm it, and a rename can be undone afterward if you change your mind.

Step 1

Getting started

Open Renamix. The window is split into two areas: your file list on the left, and the active rename rules on the right. There's nothing to configure before you begin — you can start selecting files immediately.

Step 2

Selecting files

Add files to Renamix in either of two ways:

  • Drag and drop — drag a folder or a group of files directly into the Renamix window.
  • Browse — use the file picker to select a folder or individual files.

Once files are loaded, they appear in the file list with checkboxes so you can include or exclude individual files from the current operation.

Step 3

Creating rename rules

Rules are the core of Renamix. Each rule performs one operation on the filename, and you can stack multiple rules to run in sequence. Available rule types:

  • Prefix — add text to the start of each filename.
  • Suffix — add text to the end of each filename, before the extension.
  • Replace text — find a substring and replace it with something else.
  • Remove text — strip a substring out of the filename entirely.
  • Change case — convert to lowercase, UPPERCASE, Title Case, or sentence case.
  • Extension handling — normalize or correct file extensions.
Example — Prefix rule
report.docx → 2026_report.docx
Step 4

Previewing names

As you add or edit rules, the file list updates immediately to show the resulting filename for every selected file. Nothing on disk changes at this stage — the preview is purely informational, so you can adjust your rules freely until the result looks right.

Tip: if a rule would create a filename conflict (two files ending up with the same name), Renamix flags it in the preview so you can fix it before renaming.
Step 5

Renaming files

Once the preview looks correct, select Rename files. Renamix applies your rules to every checked file in a single operation. A summary shows how many files were renamed.

Sequential numbering

For collections of similar files, Renamix can append a sequential number to each filename automatically. You control the starting number, the step between numbers, and how many digits to pad to.

Example — Sequential numbering, start 1, pad 3
photo.jpg → photo_001.jpg
photo.jpg → photo_002.jpg

Undo

If a batch rename doesn't turn out the way you expected, use Undo to revert the most recent rename operation back to the original filenames. This works even after closing and reopening the file list, as long as the files haven't been moved or renamed by something else in the meantime.

Filtering files

When working with a large folder, use filters to narrow the file list down to just the files you want to rename — for example, only files of a certain type, or only files whose names match a pattern. Filtered-out files stay untouched by any rule you apply.
