Features

Every rule you need for batch renaming.

Combine renaming operations into a single pass, preview the outcome, and only commit once you're satisfied.

Live preview

See the exact new filename for every file before you rename anything — no guessing, no surprises.

report_final_v2.pdf→2026-01-14_report_final_v2.pdf

Sequential numbering

Number files automatically as part of a rule — with control over start value, step, and digit padding.

photo.jpg→photo_001.jpg

Prefix & suffix

Add text to the start or end of filenames across an entire selection in one pass.

Replace & remove text

Find and replace any substring, or strip unwanted text like camera prefixes and timestamps.

Change case

Convert filenames to lowercase, UPPERCASE, Title Case, or sentence case in a single click.

Extension handling

Standardize or correct file extensions without touching the rest of the filename.

File filtering

Narrow a large folder down to just the files you want to rename, by name, type, or pattern.

Drag & drop

Drop folders or file selections straight onto Renamix to load them instantly.

Undo rename

Made a mistake, or changed your mind? Revert a batch rename back to the original names.

Large file collections

Built to stay fast and responsive across thousands of files in a single folder.

Batch renaming

Stack multiple rules together and apply them all to a selection in a single operation.
