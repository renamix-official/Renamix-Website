Download and Install

Downloading

The download button offers two options:

  • itch.io
  • GitHub Repository

Choose whichever source you prefer to download the installer.

Installing

  1. Read the license carefully, then accept it if you agree to the terms.
  2. Run the installer. Once complete, it will place a shortcut on your desktop that you can use to open the app.
A note on security warnings. This app is not signed with a Microsoft publisher certificate, since this is our first application. Because of this, Smart App Control (or SmartScreen) may block the installation with an "unknown publisher" warning. If this happens, you can disable that protection temporarily to proceed with the installation.

Renaming Guide

  1. Open a directory using one of these methods:
    • Click the Browse button
    • Press Ctrl+D
    • Paste a path into the text field and press Enter
  2. Select the files you want to rename (and leave out the ones you don't). See the Select Files section for details.
  3. Create your renaming rule by choosing a new name pattern for the files.
    • Be careful: two or more files cannot share the same name within the same directory. Avoid conflicts by adding a prefix or suffix that changes per file (e.g., a sequential number).
    • See the Prefix and Suffix Guide for details.
  4. Preview your changes:
    • A live preview automatically shows how each file name will look as you edit the rule.
    • To preview only the selected files, click the Preview on Selected Files radio button, or press Ctrl+P.
  5. Apply the rename:
    • Click the Rename button.
    • Confirm the notification that asks whether to rename the selected files.
    • Once accepted, the files are renamed immediately. When the progress finishes, you can check the directory to confirm the files were renamed successfully.
  6. Undo if needed:
    • If you're not satisfied with the result, undo the renaming process from the Edit menu, or press Ctrl+Z.
    • This directly reverts all the changed files in the directory.
    • See the Undo and Redo Guide for full details on how this works.

Select Files

You can select files in the table of view in a few ways:

  • Click the checkbox beside a file to select it individually.
  • Click the checkbox in the table's column header to select all files at once. Unchecking it will deselect all files.

You can also manage selection from the Edit menu, which offers these options:

  • Select All
  • Deselect All
  • First File
  • Last File
  • By index — select a specific file by its position in the table of view
  • Index range — select from one index to another (the first index must be less than or equal to the second)
Note: Every renaming, undo, and redo action will automatically deselect all selected files.

Undo and Redo Guide

Each file is treated as a node in a tree, with a parent and (optionally) children:

  • Undo replaces only the changed files with their parent version (if one exists).
  • Redo replaces only the changed files with their child version (if one exists).

After each renaming process, the changed files are saved to the undo list. When you undo, those files are moved to the redo list.

Losing your undo/redo history

The undo and redo lists are cleared if you:

  • Close the app
  • Change the path
  • Browse to a new location
  • Start a new file
  • Open a different file or directory

...unless you save first. When one of these actions is triggered, a dialog will present three options:

  • Cancel — closes the dialog and takes no action
  • Save — saves the current file before proceeding
  • Browse / Change / Close (depending on context) — ignores saving and proceeds directly with the change/close/browse/open action

See the Save Guide for more on saving files.

Save Guide

  • To save, click Save in the File menu or press Ctrl+S. Choose the destination and a name for the saved file.
  • Pressing Save / Ctrl+S again will save to that same file.
  • To save to a different location or with a different name, use Save As in the File menu.

File format

Saved files use the .rmx format. This file is carefully hashed — if you tamper with it (e.g., editing the file or changing text inside it), it will fail to open and will show an error dialog indicating the file is invalid.

Directory integrity

If the saved file references a directory whose files were modified outside the app, an error will appear indicating that some files are deleted or modified, and they will not display in the table of view. Make sure all modifications are made through the app.

If you don't need to preserve undo/redo history, you can instead open the app as a new file and select the same directory again.

Opening a saved file

Click Open File in the File menu, or press Ctrl+F.

Table of View

The table of view lists all files inside the selected directory. It has seven columns:

ColumnDescription
CheckboxSelects the file
IDA fixed identifier for each file (cannot be modified)
Current NameThe file's current name
Preview NameShows the name the file will have after renaming or when previewing rename rules
ExtensionThe file's extension, or "Directory" if the item is a folder
SizeThe file's size
StatusThe current renaming status (see below)

Possible status values

  • Ready — initial state; the file is ready to rename
  • Undone — after an undo
  • Redone — after a redo
  • Unchanged — the new name is the same as the current name
  • File Not Found — the file was deleted or modified outside the app
  • Already Exists — another file with the same name exists in the directory
  • Access Denied — you don't have permission to rename this file
  • Security Denied — the device's security settings blocked the rename
  • Renamed — the file was renamed successfully
  • Invalid Name — the new name contains invalid characters (this is checked live during editing, so in practice this status should rarely appear)

You can control which columns are visible from the View menu.

Prefix and Suffix Guide

You can add any custom prefix or suffix text. Additionally, these dynamic options are available:

Numbers

Adds a sequential number that increases with each file (1, 2, 3, 4, ...).

  • Starting number — the number to begin counting from. Must be between 0 and 999999999 (cannot be negative).
  • Number of digits — how many digits to pad the number to. Must be between 1 and 20. If a number exceeds the specified digit count, it will simply display at its natural length.
Example:
  • Starting number: 1
  • Number of digits: 2

Result: 01, 02, 03, 04, 05, ..., 10, 11, ..., 100, 101, ...

Date

Inserts a specific date, or the current date, with a separator of your choice.

Parent Folder

Inserts the name of the parent directory into the text field.

Note: This option is unavailable until you've selected a directory.

Invalid Renaming Rules

When building your rename rule, the following characters are not allowed:

< > : " / \ | ? *

If your rule includes any of these characters, an error label will appear indicating that it contains invalid characters.
